Unit

ADim

Declaration

type generic TMatrixQuantity<T> = record

Description

Represents a dynamically sized square matrix whose coefficients share one physical dimension. T is the mathematical coefficient type, normally TReal or TComplex. Matrix order is determined by the underlying TMatrix value.
