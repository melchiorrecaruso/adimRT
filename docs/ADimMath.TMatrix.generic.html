Public function SolveLinear(const AData: TVectorType): TVectorType;

Solves A*x = AData by LU factorization with partial pivoting. Raises EZeroDivide when the matrix is singular to working precision, that is when the estimated reciprocal condition number in the 1-norm is below the unit roundoff (as LAPACK xGESVX): the solution would then have no correct digits.
