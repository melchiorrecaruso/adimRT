type TCL3TrivecQuantity = record

Description

Represents a trivector of Cl(3,0) with a physical dimension.

Combines a TCL3Trivector value with a TDimension shared by all its components. Arithmetic follows both the rules of the algebra and the rules of dimensional analysis: incompatible dimensions raise EDimensionError at run time. When the symbol ADIMOFF is defined, this type is an alias of TCL3Trivector.
