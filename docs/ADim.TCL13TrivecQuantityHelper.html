type TCL13TrivecQuantityHelper = record helper for TCL13TrivecQuantity

Description

Record helper for TCL13TrivecQuantity: the methods of TCL13Trivector on dimensioned values. Only available when ADIMOFF is not defined.

Public function Conjugate: TCL13TrivecQuantity;

Public function Inverse: TCL13TrivecQuantity;

Returns the multiplicative inverse, X⁻¹ * X = X * X⁻¹ = 1. The resulting dimension is the inverse of the original dimension. Raises a floating-point exception if the value is not invertible.
