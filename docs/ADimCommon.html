Description

ADim record types and data structures.

Defines the core record types and data structures used throughout the ADimPas library, including:

  • TDimension — the SI dimension exponent record, storing the integer exponents of the eight SI base units and the steradian.

Description

Constants

BaseUnitCount = 8;

Number of SI base units tracked by TDimension.

Each base unit has a fixed index in TDimension.FExponents:

0 = kilogram (kg) 1 = meter (m) 2 = second (s) 3 = ampere (A) 4 = kelvin (K) 5 = mole (mol) 6 = candela (cd) 7 = steradian (sr)

The same order is used by BaseUnitSymbols and by the unit generator in toolkit/common.pas.

ExponentsPerWord = SizeOf(QWord) div SizeOf(smallint);

Number of 16-bit exponents that fit in one 64-bit word.

DimensionWords = (BaseUnitCount + ExponentsPerWord - 1) div ExponentsPerWord;

Number of 64-bit words needed to hold one exponent per base unit.

DimensionSlots = DimensionWords * ExponentsPerWord;

Number of exponent slots: the base units rounded up to whole words. The slots from BaseUnitCount onwards are padding and are always zero.
