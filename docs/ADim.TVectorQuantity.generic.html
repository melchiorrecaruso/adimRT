Unit

ADim

Declaration

type generic TVectorQuantity<T> = record

Description

Represents a dynamically sized vector whose coefficients share one physical dimension. T is the mathematical coefficient type, normally TReal or TComplex. Vector sizes are determined by the underlying TVector value, and binary operations require equal sizes.
